# Portfolio Website 1 (Modern)#


## Overview
A customizable portfolio website built with HTML, CSS, and JavaScript. All content is managed through the `data` folder, making it easy to update your personal information, projects, skills, and other details without modifying the main website code.


## Project Structure
```
data/
├── about-data.js
├── personal-data.js
├── projects-data.js
└── skills-tools-data.js

images-and-icons/
├── icons/
└── images/

script/
├── animations.js
├── email-sender.js
├── main.js
└── render-contents.js

styles/
├── sections-style/
└── global style files

page.html
SETUP.md
LICENSE.txt
```


## ====== To Customize This Portfolio ===== ##

### Update Content
Edit the files inside the `data` folder:

* `personal-data.js` → Personal information
* `about-data.js` → About section
* `projects-data.js` → Projects
* `skills-tools-data.js` → Skills and tools
> Changes will automatically appear on the website.


### Update Styles
Modify the CSS files inside the `styles` folder to customize the design, layout, and animations.
> Keep the data structure unchanged to prevent rendering issues.
